# MRTY1037 GitHub Pages website — USYD colours

Upload **the contents** of this folder to the root of your GitHub repository (not the containing folder). Enable GitHub Pages from `main` and `/ (root)`. Home: `index.html`.

Uses the University of Sydney masterbrand palette from the Sydney Informatics Hub `usydColours` reference: ochre `#E64626`, black `#0A0A0A`, charcoal `#424242`, white `#FFFFFF`, accent grey `#F1F1F1`. Official USYD shield/wordmark is intentionally **not included**.

- `fourier.html`: interactive 1D wave activities
- `image-lab.html`: matrix/pixel size and quantisation only
- `tutorial-3-answers.html` and `tutorial-4-answers.html`: all worksheet steps with revealable answers
- `downloads/`: current uploaded student worksheets + practice image ZIP
- `assets/`: teaching PNG files

The 2D FFT is performed in **ImageJ**, not in the browser app. If you updated an older site, overwrite all HTML pages and `usyd.css`, then refresh with Ctrl+Shift+R.

Canvas pages in the complete package contain example URLs using `YOUR-GITHUB-USERNAME` and repository name `mrty1037-labs`. Replace that prefix before publishing. If you use a different repository name, replace that as well.
